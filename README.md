# Magocoro（まごころ）

親が写真または短い動画と、ことばと声を1通のWeb手紙にまとめて送り、祖父母がリンク、画像、または動画で受け取るサービスです。

画面は日本語のみです。本文は親が書いたものがそのまま載ります。

## 使い方

1. `/` で「写真」または「動画」を選び、宛名・本文・署名を書く。声は任意。
2. 「お手紙をつくる」と `/letter/:id` の手紙ができる。
3. 「リンクをコピー」でLINEなどに貼る。写真だけで声がない手紙は「画像にして送る」（JPEG）。声またはクリップがある手紙は「動画にして送る」（端末が対応すれば MP4、なければ WebM）。
4. 受け取った人は便箋を読み、クリップや声を再生し、「読んだよ」「かわいい！」のスタンプを押せる。

共有リンクにログインはありません。手紙は作成から90日で閉じます。

## 1通に載せられるもの

- 写真 1〜3枚、または動画 1本（30秒以内）。両方は載せられない
- 声は任意（30秒以内）
- 宛名（初期値は「じいじ、ばあばへ」）
- 本文（1〜1000字）
- 署名（1〜20字）

写真は選んだあと、端末で長辺1280pxのJPEGに落とします。動画も端末で720p・30秒以内へ整えます。まとめ用の画像・動画は端末だけで作り、サーバには置きません。

## 開発

Cloudflare Pages（静的UI）+ Worker（API）+ R2（手紙JSONと素材）。画面は `LetterApi`（`src/api/letters.ts`）だけを呼び、ブラウザは R2 を直接叩きません。

```bash
npm run dev      # 開発サーバー
npm test         # Vitest
npm run lint     # oxlint
npm run build    # 型チェックと本番ビルド
```

個別テストは `npx vitest run tests/<name>` です。

## サービス案内

Magocoroは、孫のいまを、ばらばらの写真や動画ではなく、**一通の手紙**にして届けるサービスです。親が便箋に写真または短い動画、ことば、そして声をまとめると、じいじ・ばあばはいつものLINEから、リンクを開くだけで読めます。アプリの追加も、会員登録もいりません。

写真は最大3枚、または30秒以内の短い動画を1本。両方は載せません。ひとつに絞ることで、見開きのアルバムではなく、切手を貼った一枚の便箋になります。宛名の初期値は「じいじ、ばあばへ」。本文は親が書いたことばがそのまま載り、誰かが言い換えることはありません。署名を添えると、だれからの手紙かが一目でわかります。声は任意です。吹き込みがあれば、開いたときに孫の声や、親が添えたことばが手紙と一緒に届きます。

できた手紙は、リンクをコピーしてLINEに貼るだけで渡せます。写真だけで声がない手紙はJPEG。声や動画が入っている手紙は、便箋ごと録画した1本の動画になります。動画の中では、クリップは切手枠の位置で再生され、声は始まりと同時に流れます。iPhoneではMP4として保存しやすく、写真アプリやLINEから開きやすい形を優先しています。

受け取った人は、便箋を読み、写真を見て、動画や声を再生できます。「読んだよ」「かわいい！」のスタンプで、読んだ気持ちをそのまま返せます。回数は手紙に残るので、届いたあとにもう一度開いても、返事が消えていません。

ログインはありません。URLを知っている人が手紙を開けます。手紙は作成から90日で閉じます。長く保管するアルバムではなく、いまの一通を、いま届けるための手紙です。
